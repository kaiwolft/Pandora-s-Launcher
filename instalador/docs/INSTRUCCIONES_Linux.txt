PANDORA'S TOWER - Dionixu's Launcher
====================================

AVISO LEGAL - LEE ANTES DE INSTALAR
  * Este instalador NO incluye el juego. Solo contiene el launcher, las mejoras y las herramientas.
  * Necesitas DOS copias ORIGINALES de Pandora's Tower para Wii, extraidas por ti de tus propios discos:
      - Version americana (NTSC-U, ID SX3EXJ)              -> juego y textos (ingles, espanol, frances)
      - Version japonesa Pandora no To (NTSC-J, ID SX3J01) -> voces japonesas
  * El instalador comprueba ambas copias (ID y huellas MD5) y SOLO funcionara con tu copia oficial.
    Una copia modificada, incompleta o de otra region sera rechazada.
  * Las voces japonesas se reconstruyen en tu equipo a partir de TUS discos: el instalador no trae audio del juego.
  * No se acepta ni se fomenta la pirateria. Necesitas tu copia oficial. No descargues el juego de internet.
  * Proyecto de aficionados sin fines de lucro, sin relacion con Nintendo, Ganbarion ni XSEED Games.

INSTALACION EN LINUX (AppImage; Debian 12, Ubuntu 22.04, Linux Mint 21, Fedora 36 o mas nuevos; 64 bits)
  Que necesitas:
    - Unos 10 GB libres (unos 6 GB al terminar).
    - Tus dos copias del juego (.rvz, .iso, .wbfs, .wia o .gcz): version americana y japonesa.
    - Tu propio Dolphin para Linux (no se incluye). Recomendado: Flatpak (version actual de Dolphin):
        sudo apt install flatpak
        flatpak remote-add --if-not-exists flathub https://dl.flathub.org/repo/flathub.flatpakrepo
        flatpak install flathub org.DolphinEmu.dolphin-emu
      Tambien sirve un Dolphin compilado por ti (elige dolphin-emu y dolphin-tool en el instalador).
      El paquete 'dolphin-emu' de apt en Debian/Ubuntu suele ser muy antiguo y no se recomienda.
    - FUSE para abrir AppImages (casi todas las distribuciones lo traen). Si no abre:  sudo apt install libfuse2
      (o ejecuta:  ./Instalar_Pandoras_Tower-x86_64.AppImage --appimage-extract-and-run)
    - Opcional, para el volumen en vivo del menu de pausa: sudo apt install pulseaudio-utils   (pactl)
  Pasos:
    1. Copia el AppImage a tu equipo y dale permiso de ejecucion:
         chmod +x Instalar_Pandoras_Tower-x86_64.AppImage
       (o clic derecho -> Propiedades -> Permitir ejecutar como programa).
    2. Abrelo con doble clic o desde una terminal:  ./Instalar_Pandoras_Tower-x86_64.AppImage
    3. Elige el idioma y acepta el aviso legal.
    4. Elige tu Dolphin (se detecta solo si esta instalado) y tus dos copias del juego.
    5. Elige la carpeta de instalacion (por defecto: ~/Games/Pandora's Tower) y los accesos directos
       (menu de aplicaciones y escritorio).
    6. Pulsa INSTALAR. Al terminar, el launcher se abre solo en una ventana. El AppImage ya no hace falta.
  Que funciona en Linux:
    - Ventana del launcher en X11 y en Wayland (Chromium elige solo; Dolphin va por XWayland).
    - Puente del mando: L3 + R3 y F1 abren el menu de pausa, foco de ventanas, ventana sin bordes y volumen en vivo.
    - Dolphin escucha mando y teclado aunque crea que no tiene el foco (necesario en Wayland).
    - Mando: cualquier mando compatible con SDL (Xbox, PlayStation, 8BitDo...). Teclado y raton por XInput2.
    - Mandos genericos (DirectInput, p. ej. Shanwan): el menu del launcher los entiende aunque mezclen los botones.
      Si en el juego los botones salen cruzados: Ajustes -> Controles -> CONTROLES AUTOMATICOS = No, y configura
      el mando una sola vez en Dolphin (Controles -> Mando Clasico). El launcher ya no pisara esa configuracion.
  Configuracion de Dolphin: se usa una carpeta propia (dolphin-user dentro de la instalacion);
  tu configuracion normal de Dolphin no se toca.
  Desinstalar: borra la carpeta de instalacion y ~/.local/share/applications/pandoras-tower.desktop.

INSTALLING ON LINUX (AppImage; Debian 12, Ubuntu 22.04, Linux Mint 21, Fedora 36 or newer; 64-bit)
  You need:
    - About 10 GB free (about 6 GB once finished).
    - Your two game copies (.rvz, .iso, .wbfs, .wia or .gcz): North American and Japanese versions.
    - Your own Dolphin for Linux (not included). Recommended: Flatpak (current Dolphin):
        sudo apt install flatpak
        flatpak remote-add --if-not-exists flathub https://dl.flathub.org/repo/flathub.flatpakrepo
        flatpak install flathub org.DolphinEmu.dolphin-emu
      A Dolphin you built yourself also works (pick dolphin-emu and dolphin-tool in the installer).
      The 'dolphin-emu' apt package on Debian/Ubuntu is usually very old and not recommended.
    - FUSE to open AppImages (most distributions have it). If it does not open:  sudo apt install libfuse2
      (or run:  ./Instalar_Pandoras_Tower-x86_64.AppImage --appimage-extract-and-run)
    - Optional, for live volume in the pause menu: sudo apt install pulseaudio-utils   (pactl)
  Steps:
    1. Copy the AppImage to your computer and make it executable:
         chmod +x Instalar_Pandoras_Tower-x86_64.AppImage
       (or right click -> Properties -> Allow executing as program).
    2. Open it with a double click or from a terminal:  ./Instalar_Pandoras_Tower-x86_64.AppImage
    3. Pick the language and accept the legal notice.
    4. Pick your Dolphin (auto-detected when installed) and your two game copies.
    5. Pick the install folder (default: ~/Games/Pandora's Tower) and the shortcuts (app menu and desktop).
    6. Press INSTALL. When it finishes, the launcher opens in a window. The AppImage is no longer needed.
  Works on Linux: launcher window on X11 and Wayland, gamepad bridge (L3 + R3 and F1 open the pause menu, window
  focus, borderless window, live volume), any SDL gamepad, keyboard and mouse through XInput2. Generic DirectInput
  pads work in the launcher menu; if buttons are swapped in game, set Settings -> Controls -> AUTOMATIC CONTROLS = No
  and configure the pad once in Dolphin (Controllers -> Classic Controller); the launcher will keep your setup.
  Dolphin uses its own folder (dolphin-user inside the install); your normal Dolphin settings are untouched.
  Uninstall: delete the install folder and ~/.local/share/applications/pandoras-tower.desktop.
